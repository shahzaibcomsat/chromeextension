          1. Install the WP x MCP plugin on your WordPress site (download the zip from the link below, then Plugins → Add New → Upload Plugin).
            2. 
                
          2. In WP Admin go to WP x MCP → Settings and copy the MCP Endpoint URL into the field below.
            3. 
                
          3. In WP x MCP → API Keys create a key, then paste it into the API Key field. Use the 👁 button to reveal/hide.
            4. 
                
          4. Click Save & Connect, then Test Connection. A green Connected (N tools) badge means the plugin exposed its tools to Shahzaib SEO.
            5. 
                
          5. Open any audited page on your site and click the orange MCP Fix button in the footer of the popup. Pick which categories to fix in the What to fix panel below — changes are written back to your post via the WP REST API.
            6. 
              
          
              
          
                Tip: MCP Fix only works on WordPress pages where the WP x MCP plugin can resolve a Post ID. If the page is a static front page or archive, open the actual post in WP admin and re-run the audit from there.
